Peach Time

A clickable preview of Peach's self-hosted time tracker. Every screen is a snapshot of the working app, linked together so you can walk through it as an employee, a project manager or an administrator.

Fictitious demo data. The people, hours, rates, budgets and fees are invented for this preview. Client names are made up too; some project and task names come from Peach's Harvest screenshots. Saving, timers, filters and exports need the real server, so they're switched off here.

Employee

My Time

  • My Time: dayAdd time with the Project / Task picker, see the week strip and today's entries.
  • My Time: weekWeek grid with daily and row totals, add rows, copy last week's rows, submit.
  • Last week (rejected)A week sent back with the reviewer's comment, ready to fix and resubmit.
  • Edit an entryChange project, task, notes, duration or date, with the change history below.
  • Entry historyEvery change to an entry, who made it and why.

Reports and account

  • My reportsAn employee's own totals, chart and breakdowns. No money columns.
  • My detailed timeEvery entry, with search, sorting, columns and exports.
  • My summaryLogged vs. scheduled hours and billable utilization, with definitions.
  • Account & securityProfile, password, two-step verification and signed-in sessions.
  • Sign inInvitation-only sign-in. Administrators also enter an authenticator code.

Works in this preview

  • The Project / Task picker: open it, press Backspace (or choose ← All projects) to search every project, type retainer design, then use the arrow keys and Enter.
  • Duration hints: type 1.5, 1:30 or 90m and see each read as 1 h 30 min.
  • Moving between screens, and the phone layout (narrow your window).

Needs the real app

  • Saving and editing entries, timers, submitting and approving weeks.
  • Report filters, drill-downs to other entries, CSV and Excel exports.
  • Imports, settings changes and sign-in. These run on Peach's own server.
