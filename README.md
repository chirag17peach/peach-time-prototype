# Peach Time: clickable prototype

A static, clickable preview of Peach Time, Peach's self-hosted time tracker (its Harvest replacement).

Open it here: https://chirag17peach.github.io/peach-time-prototype/

- Every screen is a snapshot of the working app, linked together so you can walk through it as an employee or an administrator.
- The people, hours, rates, budgets and fees are fictitious, and so are the client names.
- Saving, timers, filters and exports are switched off: they need the real server.

This repository holds only these static pages, not the application's source code.
