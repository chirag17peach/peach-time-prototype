Budget rules
One budget per project
Each project has one authoritative budget mode, so task and project budgets are never added together.
Hour budgets
Count all project time unless the project counts billable time only.
Effort-value budgets
Billable hours × billing rates (not cost rates). Hours without a rate are listed as unvalued.
Monthly retainers
Calendar months in America/Halifax, no rollover. Each month keeps the allowance that applied to it.
No budget vs zero
“None” means nothing is tracked; a zero budget is over as soon as any time is logged. Percentages are N/A for both.
Alerts
In-app alerts at 75, 90, 100%, once per threshold per period.
